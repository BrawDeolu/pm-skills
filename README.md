# PM Skills Pack

Six Claude skills for the day-to-day work of a product manager, built from real workflows: writing PRDs, grooming backlogs, writing tickets, making demo videos, writing product guides and launching work publicly.

Created by Moses Afolabi ([mosesafolabi.com/skills](https://mosesafolabi.com/skills)). Free to use, share and adapt under the MIT licence.

**Download:** grab the zips from [mosesafolabi.com/skills](https://mosesafolabi.com/skills), or clone this repo.

## The skills

| Skill | What it does |
|---|---|
| prd-writer | Writes PRDs and FRDs with requirement tables and Given/When/Then acceptance criteria. Also reviews PRDs and flags what will break. |
| dev-ticket-writer | Turns specs or prototypes into plain-English tickets split into [UI] and [API], with Why, Scope, Not included, Acceptance criteria and Tech notes. |
| backlog-grooming-pack | Grooms backlog items into one sprint pack: FRD, data insights, clickable prototype and tickets per item. |
| product-demo-video | Plans and produces demo videos: script, shot list, natural AI voiceover, cover thumbnail and post copy. |
| annotated-product-guide | Writes feature guides with annotated screenshots (arrows, numbered labels, redacted personal data). |
| pm-launch-kit | LinkedIn posts, case studies, community post titles and designed cover images for shipped work. |

## How to install

**Claude (web, desktop or mobile)**
1. Go to Settings, then Capabilities, and make sure Skills are turned on.
2. Upload a skill's zip file (for example `prd-writer.zip`).
3. Repeat for each skill you want.

**Claude Code**
Unzip each skill into `~/.claude/skills/` so you end up with, for example, `~/.claude/skills/prd-writer/SKILL.md`.

Each skill triggers on its own when your request matches its description, or you can ask for it by name ("use prd-writer to...").

## Make them yours

Every skill says to follow your team's own template or house style first. Edit the SKILL.md files to add your company's PRD template, ticket fields or brand colours.
